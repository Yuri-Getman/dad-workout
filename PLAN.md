# План: приложение для тренировок

Мобильное веб-приложение (PWA) с программой тренировок на 3 года для отца.
Работает на Android, ставится на главный экран, работает без интернета, все данные хранятся только на телефоне.

## 1. Исходные данные

- Возраст 50 лет, рост 192 см, вес 84 кг (ИМТ около 22,8). Эти данные отец проверит и поправит при первом запуске.
- Уровень: давно не занимался, только утренняя разминка. Может подтянуться 10 раз и сделать 15 обычных отжиманий (тоже уточняется тестом при первом запуске).
- Цели: здоровье и тонус, меньше жира, сила, подвижность суставов, выносливость, упор на грудные мышцы.
- Ограничение: протрузии в позвоночнике. Исключаем тяжёлые осевые нагрузки и скручивания под весом, упор на стабилизацию корпуса и технику. Программу показать врачу или специалисту по ЛФК.
- Инвентарь: гантели (вес уточняется в приложении), турник, коврик. Резинок и скамьи нет.
- Режим: 2-3 тренировки в неделю по 40 минут.
- Видео на русском языке, из YouTube. Картинка для каждого упражнения как запасной вариант без интернета.

## 2. Стек и ограничения

- Чистый JavaScript (ES-модули), HTML, CSS. Без сборки и без зависимостей.
- Данные: IndexedDB. Офлайн: service worker. Публикация: GitHub Pages через GitHub Actions.
- Логика (прогрессия, расписание, статистика) вынесена в модули без привязки к браузеру и покрыта тестами (`node --test`).
- Изначально планировались Vite + Preact, от них отказались: в среде разработки нельзя установить пакеты, а без сборки проще публиковать и сопровождать.

## 3. Функции

**Первый запуск**
- Рост, вес, возраст (предзаполнены, можно поправить).
- Дни тренировок (например, пн/ср/пт) и дата старта.
- Гантели: цельные или разборные, какой вес (шаг веса, минимум и максимум).
- Тест на максимум: подтягивания, отжимания. Стартовые нагрузки считаются от этих данных.
- Первая тренировка калибровочная: отец вводит, сколько реально сделал, нагрузки подстраиваются.

**Экран «Сегодня»**: ближайшая тренировка, кнопка «Начать».

**Тренировка**
- Видео (YouTube) и картинка к каждому упражнению, краткие подсказки по технике.
- Ввод повторов и веса по каждому подходу.
- Таймер отдыха между подходами и таймер для упражнений на время.
- Звук и вибрация таймера: отдельные переключатели.
- Экран не гаснет во время тренировки. Время считается по моменту окончания, чтобы таймер не врал в фоне.

**Итоги**: заметка к тренировке (тяжело или легко, другие замечания).

**История и календарь**: пройденные, пропущенные, запланированные тренировки.

**Статистика**: тренировок в неделю, объём (вес × повторы), личные рекорды, графики по упражнениям, вес тела.

**Программа**: просмотр всех 3 лет по фазам и блокам.

**Настройки**: тёмная тема, звук, вибрация, время отдыха, экспорт и импорт данных файлом, напоминание о резервной копии раз в месяц.

## 4. Программа тренировок

Хранится отдельным JSON-файлом в репозитории (`data/program.json`). Её можно пересматривать каждые 6 месяцев, не переписывая приложение. История отца при этом сохраняется.

Структура: 6 фаз по 6 месяцев, внутри блоки по 4-6 недель, затем облегчённая неделя.

| Фаза | Месяцы | Фокус |
|---|---|---|
| 1. Адаптация и основа | 1-6 | Техника, корпус, подвижность (4-6 недель), затем рост объёма. Грудь: отжимания и жимы гантелей лёжа на полу |
| 2. Объём | 7-12 | Больше подходов, акцент на грудь, подтягивания с весом |
| 3. Сила | 13-18 | Тяжелее и меньше повторов в безопасном диапазоне |
| 4. Мышечная масса | 19-24 | Разделение верх/низ, больше упражнений на грудь и спину |
| 5. Выносливость и сила | 25-30 | Круговые блоки, упражнения на время, плотность тренировки |
| 6. Закрепление | 31-36 | Лучшие блоки, новые цели |

Структура одной тренировки (около 40 минут): разминка суставов 5-7 минут, основная часть около 30, растяжка и подвижность 5.
Первые 2 недели по 2 тренировки в неделю, затем 3.

Подробная программа первых 6 месяцев пишется на этапе 5, остальные фазы детализируются позже.

## 5. Прогрессия (автоматическая)

Прогрессия привязана к номеру тренировки, а не к дате, поэтому переносы её не ломают.

- **Диапазон повторов** для каждого упражнения (например, 8-12). Все подходы дошли до верха диапазона: вес растёт на минимальный шаг, повторы снова идут от нижней границы.
- **Подтягивания**: диапазон 6-10, 3-4 подхода, запас 1-2 повтора, без раскачки. Дошли до 10 во всех подходах: добавляется вес (гантель между стопами, +1-2 кг).
- **Отжимания**: лестница усложнений: медленный негатив 3 секунды, ноги на возвышении, руки на гантелях для большей амплитуды, ноги выше плюс пауза внизу. Диапазон 8-12. Все подходы дошли до верха: переход к следующему варианту.
- **Упражнения с гантелями**: тот же принцип, шаг веса зависит от гантелей (из настроек).
- **На время**: +5 секунд.
- **Не получается добрать повторы** несколько тренировок подряд: приложение предлагает оставить вес или снизить.
- **Перерыв больше 14 дней**: предлагается облегчённая тренировка (на 10-20% легче).
- Приложение только предлагает изменение нагрузки, отец может согласиться или оставить как есть.

## 6. Переносы тренировок

Тренировки в программе идут по порядку (№1, №2, ...), даты лежат поверх этого порядка.

- **Перенести только эту**: выбрать новую дату, остальной план не трогается. При конфликте с другой тренировкой приложение предупреждает.
- **Перенести эту и все следующие**: все невыполненные тренировки сдвигаются на столько же дней.
- **Пропустить**: тренировка помечается пропущенной и видна в статистике, план не сдвигается.
- **Отмена последнего переноса**.

## 7. Этапы разработки

1. **Каркас**: PWA (манифест, service worker, иконки), GitHub Pages, пустое приложение ставится на телефон.
2. **Данные и логика**: формат программы, база, прогрессия, переносы, тесты.
3. **Экран тренировки**: ввод подходов, таймеры, звук, вибрация.
4. **История, заметки, статистика**.
5. **Контент**: подбор роликов и картинок, подробная программа на первые 6 месяцев.
6. **Тема, настройки, резервные копии**, проверка на телефоне отца.

## 8. Известные ограничения

- YouTube-ролики встраиваются только при наличии интернета, скачивать их нельзя. Для работы без интернета у каждого упражнения есть картинка.
- Данные только на телефоне: если очистить данные браузера, история пропадёт. Поэтому нужен экспорт и импорт файлом.
- При заблокированном экране Android может приглушать звук и вибрацию PWA. Гарантировать их нельзя, экран во время тренировки держим включённым.
- Репозиторий публичный (требование бесплатного GitHub Pages). Личная история тренировок в нём не хранится, только код и программа.
