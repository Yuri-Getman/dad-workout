# Тренировки

Мобильное веб-приложение (PWA) с программой тренировок на 3 года: прогрессия нагрузок, видео и описание техники,
таймеры отдыха и упражнений на время, история, заметки, статистика и вес тела.
Все данные хранятся только на телефоне, приложение работает без интернета.

## Как установить на телефон (Android)

1. Один раз включите публикацию: **Settings → Pages → Source: GitHub Actions**.
2. После публикации (вкладка **Actions**, зелёная галочка) откройте в Chrome на телефоне
   `https://<ваш-логин>.github.io/dad-workout/`.
3. Меню ⋮ → **Установить приложение**. Значок появится на главном экране.
4. При первом запуске приложение спросит рост, вес, возраст, сколько раз получается отжаться и подтянуться,
   какие есть гантели и в какие дни тренироваться.

## Структура

| Путь | Что там |
|---|---|
| `data/program.json` | Программа: шаблоны тренировок, блоки, фазы |
| `data/exercises.json` | Упражнения: название, техника, видео (YouTube), картинки, лестницы усложнений |
| `js/logic/` | Логика без привязки к браузеру: прогрессия, расписание, статистика, копии (покрыта тестами) |
| `js/ui/`, `js/app.js`, `js/store.js` | Экраны и состояние приложения |
| `sw.js` | Офлайн-режим |
| `tests/` | Тесты (`node --test`) |
| `tools/e2e.cjs` | Проверка в настоящем браузере (нужен playwright) |
| `PLAN.md` | План проекта |

## Разработка

```sh
node --test                       # тесты логики и содержимого программы
python3 -m http.server 8000       # открыть http://localhost:8000
```

Сборки нет: это обычные ES-модули. При добавлении нового файла в `js/`, `css/`, `data/` или `icons/`
внесите его в `PRECACHE` в `sw.js` (тест `tests/sw.test.js` напомнит). Версия кэша подставляется
автоматически при публикации.

## Как добавить видео и картинки к упражнению

В `data/exercises.json` у упражнения (или его варианта) укажите:

```json
"video": "ID_ролика_с_YouTube",
"image": "img/название.jpg"
```

`ID` это часть после `v=` в ссылке на ролик. Видео встраивается без скачивания и требует интернета,
картинку из папки `img/` нужно добавить в `PRECACHE`, чтобы она работала офлайн.
